# 第一部分：代码规范

## 布局与命名
- 使用`lua/`、`dsh/`、`python/`存放实现，各自内置`tests/`，使用`protocol/`存放协议及样例、`docs/`存放文档。
- 文件、Lua/Python变量及函数用`snake_case`，JS变量及函数用`camelCase`，常量用`UPPER_SNAKE_CASE`。

## Lua
- 钩子命名为`on_<事件>`并集中注册，签名及返回值须符合对应REPENTOGON文档。([repentogon.com](https://repentogon.com/enums/ModCallbacks?utm_source=openai))
- 所有自定义变量使用`local`，禁止写入`_G`或覆盖宿主全局。
- 文件读写与JSON解析使用`pcall`，失败时记录错误并进入兜底。
- 使用逐帧状态机检查可配置截止帧，超时执行协议定义的安全动作并丢弃迟到响应，禁止忙等。
- 仅读写约定目录内的本地JSON，禁止联网。
- 日志包含级别、模块、请求ID及错误码，同类错误限频且不得包含密钥。

## JS
- 使用ESM并声明`"type":"module"`，禁止混用`require`。
- 异步调用必须等待或显式捕获错误，模型调用设置截止时间并取消请求，取消不可用时隔离迟到结果。
- 每个目标文件仅允许一个写者，先写同目录唯一`.tmp`文件并关闭，再`rename`替换，失败须保留旧文件并清理临时文件。
- 输入与模型输出均按协议校验版本、必填项、类型、范围、动作白名单及请求ID，不合格不得发布。
- 禁止吞异常、同步阻塞轮询、执行模型返回代码或允许模型指定文件路径。

## Python
- 脚本使用`main()`及入口守卫，导入时不得读写文件、联网或启动进程。
- mock与模拟器默认离线，使用固定种子和版本化样例，失败返回非零退出码。

## 注释与文档
- 为公共接口、协议字段、超时单位、兜底及非显然逻辑注明约束与原因，并在README提供安装、运行及测试命令。

# 第二部分：团队协作规范

## 分支与范围
- 分支使用`agent/<任务号>-<主题>`，提交使用`类型(scope): 描述`，例如`fix(lua): 丢弃过期响应`。
- 开工前在任务单声明负责人、目录及验收项，仅修改已声明目录，共享文件须指定唯一负责人。
- 扩大范围或修改他人文件前必须取得负责人书面批准并更新任务单。

## 接口变更
- 协议变更先提交字段差异、版本策略及迁移方案，经三端负责人批准后同步更新协议、实现和契约测试再合并。

# 补充条款（同一份规范的细化，2026-11-07 补）

## 错误码（三端统一）
- 只允许五类：`IO`、`TIMEOUT`、`VALIDATION`、`MODEL`、`INTERNAL`；日志与 decision.json 里出现的错误必须归到这五类之一。

## 路径安全
- JS 与 Python 写文件前，必须校验规范化后的路径与父目录真实路径都在白名单内；拒绝越界、路径穿越和指向别处的符号链接。

## Python 细化
- 函数标注参数与返回类型；依赖声明并锁版本；读写显式指定 UTF-8。
- 外部进程用参数数组启动并设超时，禁止 `shell=True`；禁止裸 `except`。
- 测试不得访问真实模型或修改生产目录，临时文件自动清理。
